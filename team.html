Jamaica Internship
New

Join Flash as a Developer Intern and gain hands-on experience building cutting-edge Bitcoin and Lightning Network applications. This is a unique opportunity for university students to work on real-world fintech projects while learning about blockchain technology and financial innovation in the Caribbean.

Prerequisite Skills:

  • Currently enrolled in a Jamaican university (Computer Science or related program)
  • Basic understanding of at least one programming language
  • Computer with reliable internet access
  • Familiarity with version control (Git) is a plus
  • Available 15-20 hours per week

What You'll Do:

  • Assist in developing and maintaining Flash's web and mobile applications
  • Work with modern technologies including JavaScript, React, and Node.js

  • Participate in code reviews and team meetings
  • Contribute to documentation and testing efforts

Ideal Candidate:

  • Currently enrolled in a Computer Science or related degree program at a Jamaican university
  • Basic understanding of programming concepts (TypeScript, React-Native, Docker)
  • Familiarity with HTML, CSS, and web development fundamentals
  • Prompt Engineering skills for AI agents (e.g., ChatGPT, GitHub Copilot)
  • Strong problem-solving skills and eagerness to learn
  • Interest in Bitcoin or fintech
  • Available for 15-20 hours per week during semester (flexible schedule)
  • Excellent communication skills and ability to work in a team
